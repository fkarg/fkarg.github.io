## The project

Triplum is a Python library for composing and comparing document-search and knowledge-graph experiments. The design favors small, replaceable steps—such as loading, chunking, embedding preparation, storage, and caching—so pipelines can be tested and compared without committing to a single end-to-end architecture.

## Current scope

The project is under active development. Its data records, loaders, chunking, storage, and computation-cache foundations are implemented. Indexing prototypes remain under review; a supported end-to-end retrieval pipeline is not available yet. The project documentation distinguishes implemented components from intended future flow.
